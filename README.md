# Pembuatan Website Layanan Pengaduan Masalah di Lingkungan Masyarakat Desa “SuaraDesa”

## Tujuan Aplikasi
1. Mempermudah masyarakat desa dalam menyampaikan laporan, keluhan, atau aspirasi kepada pihak desa.
2. Meningkatkan transparansi dan responsivitas pemerintah desa terhadap berbagai permasalahan masyarakat.
3. Membangun komunikasi dua arah yang efektif antara warga desa dan pemerintah desa melalui platform digital.

## Fungsi Aplikasi
Website **SuaraDesa** berfungsi sebagai media layanan pengaduan masyarakat desa, yang memungkinkan pengguna untuk:
- Mengirimkan laporan atau keluhan secara online.
- Memberikan kemudahan bagi pihak desa untuk mengelola, menindaklanjuti, dan memberikan respon atas setiap pengaduan.
